This is the DEMO folder shown on akcreation-apps.com/wedding-invitations/.
Couple names (Rohan & Priya) and all other details are placeholders.

Asset list:
  groom.jpg   — groom portrait (recommended ~800x1000)
  bride.jpg   — bride portrait (recommended ~800x1000)
  music.mp3   — optional ambient background track (keep short, < 2 MB)

And one file goes directly inside this /demo/ folder (NOT this assets folder):

  og.jpg      — Open Graph share image (lives at demo/og.jpg)
              — Preview card when the link is shared on WhatsApp / FB / iMessage.
              — Recommended: 1200 x 630 px, JPG (quality ~85), under 300 KB.

If music.mp3 is absent, the music button hides itself automatically.
